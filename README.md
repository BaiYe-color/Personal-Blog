# 个人 Sakura 博客前端

独立于 Halo 的个人博客前端。项目直接位于本目录，原始主题保留在 `模板/halo-theme-sakura`。

## 启动

需要 Node.js 22 或更新版本，无需安装第三方依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:5173 。也可以执行 `node scripts/server.mjs`。

`npm run build` 生成 `dist/`；`npm run preview` 预览生成结果；`npm run check` 检查 JavaScript 语法。启动服务后执行 `npm run verify` 检查演示数据引用的静态资源和直接访问子页面的路由。

## 页面

- `/` 首页，三层整屏切换：大图与动态命令行、四向指南针、最新文章。
- `/articles` 文章；`/posts/:slug` 文章阅读、目录、代码复制、图片预览。
- `/articles/categories` 和 `/articles/tags` 是文章下两个同级子页面，使用封面 + 名称 + 简介的横向书签列表。
- `/articles/categories/:slug` 和 `/articles/tags/:slug` 显示对应文章。
- `/links` 友链；`/photos` 分组相册与图片预览；`/moments` 瞬间时间线；`/about` 关于。
- `/music` 音乐封面收藏页，点击封面选择歌曲；播放器不随页面跳转销毁。演示数据的 `src` 为空，显示“音源待添加”，接入后台后为它填入可播放音频 URL。
- `/guestbook` 留言板，包含昵称、留言输入、字数统计与留言气泡。前端阶段只在当前浏览器保存留言，尚未公开提交，也不能跨用户共享。后台阶段替换 `src/api.js` 中的留言接口。
- `/pet` 看板娘页，包含页顶图与预留的空白内容区。
- `/login` 管理入口占位页，本阶段没有实现认证或后台。

支持明暗主题切换、搜索、分页、手机导航、浏览器前进后退和直接刷新子页面。部署到静态托管时将非文件路由回退到 `index.html`。当前为客户端渲染，SEO 与社交分享预渲染尚未实现。

明暗切换使用太阳/蓝天云朵与月亮/星空两种胶囊开关样式，圆形滑块在左右两侧过渡。支持鼠标、触摸和键盘，当前模式保存在浏览器中；减少动画偏好下直接切换。

首页命令行显示 `C:\Users\BaiYe>`，每条代码、指令或句子完整输入后停留五秒，再逐字删除、随机选择不同内容逐字输入；输入每字 70ms、删除每字 34ms，光标持续闪烁。文本库位于 `src/hero-terminal.js`，仅作展示，不执行命令；离开首页后停止计时器。减少动画偏好下直接换成完整文本。全站底部说明、首页提示条和留言板提示框已移除，留言仍使用本地保存。

首屏底部的 `scroll@home:~$ >_` 按钮切换欢迎界面和个人简介，不自动滚动。展开时欢迎文字与动态命令行淡出，默认头像和简介面板上浮至中央；收起时面板下沉，欢迎界面恢复。简介使用 `C:\Users\BaiYe>` 和“白晔”，内容位于 `public/data/content.json` 的 `site.profile` 中。GitHub、Bilibili 气泡沿用 `site.socials` 的链接，微信和 QQ 打开二维码浮窗；将图片放入 `public/assets/`，把 `site.profile.wechatQr`、`qqQr` 填为 `/assets/…`。未配置时明确显示“二维码待添加”。

`src/palette.css` 统一管理三色配色：浅紫 `#E1DBE9`、杏色 `#F5C386`、雾蓝 `#9CBCE3`。原色用于按钮、边线和装饰，文字使用对应深色衍生色；分类为蓝色气泡、标签为紫色气泡，时间轴与书签卡片交替使用三色。夜间模式采用深色底与柔和的三色表面。

首页使用 `src/home.js` 和 `src/home.css` 管理整屏层级。一次滚轮手势（包含惯性尾部）、触屏上下滑动或方向键/PageUp/PageDown 切换一层；右侧圆点也可直接选择。指南针支持拖动和左右方向键，悬停或聚焦封面也会转向。北方为文章、西方为相册、南方为音乐、东方为瞬间；中心只有刻度和指针，没有背景图，也不再显示当前页面名称。所指封面同步成为整层背景，叠加模糊毛玻璃蒙版。四张封面与对应页面页顶共用 `site.pageCovers` 配置。

最新文章层迁入 RhineLabUI 的真实三维档案阵列，直接使用模板的完整场景渲染、原 GLB 模型、磨砂透光材质、暖色灯光、环境遮蔽与景深，保留长焦斜视构图、抬升波浪、平面拖动与持续惯性。界面按原版比例重排，使用本地 MiSans 字体和长横线、细刻度等装饰。首次进入播放欢迎、阵列转入和编号显现的过渡。上/下按钮和刻度选文章，左/右按钮依次切换全部文章、各分类、各标签，每组记住上次选中的文章；聚焦阵列或控件后用方向键选档、Enter 阅读，PageUp/PageDown 仍切首页层。该层按发布日期倒序，移除右上角排序按钮；保留文章日期、多分类和多标签气泡，读取按钮进入现有文章阅读页。左下角为当前组的文章序号 / 总数。为减少卡顿，降低阴影及后期采样、采用自适应渲染分辨率，关闭静止起伏与鼠标视差，静止后停止渲染循环、操作时唤醒。资源首次进入第三层才加载，隐藏时暂停渲染、离开首页释放；静态本地 Three.js 模块随构建发布，无 CDN 依赖。迁移范围及来源许可见 [docs/rhine-migration.md](docs/rhine-migration.md)。

指南针采用轻透圆形刻度、蓝色弧线和杏色单向指针，仅朝向选中的页面。右下角文案“循着好奇心，去下一段风景。”由 `src/compass-caption.js` 管理，每次进入这一层时逐字出现，完成后保留闪烁光标；离开时停止输入，减少动画模式直接显示整句。左上角日期以大号杏色数字叠排白色大写月份，英文月份及 AM/PM 使用本地 SVG 断笔几何艺术字。`src/home-clock.js` 固定使用 `Asia/Shanghai` 和 12 小时制，不受访客所在时区影响，每秒检查日期与时间；离开首页时清理计时器。显示常见公历、农历节日，无节日时隐藏分隔线与节日名。清明节目前收录 2026 年度日期（[香港天文台年历](https://www.hko.gov.hk/en/gts/astron2026/files/2026cal04.pdf)）；其它年度日期和个人纪念日可通过 `site.festivals` 配置，例如 `{"2026-10-04": "小站生日"}`。

页眉右侧的 GPT 挂坠支持限距拖动（125px）、悬停晃动、弹簧回弹，拖动后松手回到页面顶部（首页回到第一层）；也可直接点击或用键盘 Enter/空格触发。首页三层的页眉都保持透明，不加底色或阴影；最新文章层使用深色导航文字。首页所有层的页眉与挂坠默认渐隐，鼠标移动到顶部区域才渐显，切层不会自动显示；键盘聚焦导航和手机轻触顶部区域仍可唤出导航。系统开启减少动画时不播放弹簧和切层过渡动画。

## 数据与后续后台

`public/data/content.json` 包含全部演示数据，`src/api.js` 是数据读取入口。后续用真实 API 替换数据服务，并保留或映射当前字段。

文章包含 `publishedAt`、`updatedAt`、`categories[]`、`tags[]`。支持多个分类和标签，文章卡片和阅读页都显示日期及气泡。列表支持按发布/更新时间倒序排列（最新在上），左侧时间线向上，日期格式为 `26/10/4`。排序和页码保存到 URL，可刷新和前进后退恢复。分页只更新文章列表，保留页眉、首屏和播放器。相册和音乐分组同样只更新图库。

正文采用结构化 blocks（paragraph、heading、quote、code、image），文本统一转义，不直接插入未处理 HTML。后端若输出 Markdown/富文本，需额外实现安全渲染。分类与标签都包含 slug、名称、简介和封面。留言也按纯文本安全展示。`npm test` 验证日期排序、多分类、命令行动画、挂坠、滚轮手势惯性、指南针角度及档案选择/分类记忆/惯性吸附。

## 迁移来源

直接复用 Sakura 2.5.0 已编译主样式与本地图片，改写首页、文章、友链和瞬间的 DOM 结构以去除 Thymeleaf/Halo 数据依赖。相册保留瀑布流布局，使用原生 CSS 和 dialog 实现分组/预览，未迁入原 Isotope/Fancybox 依赖；原主题 JS 依赖 Halo 配置与 Pjax，因此浏览器交互改为独立实现。

原主题 MIT 许可见 `public/assets/SAKURA-LICENSE`。本地附带图片仅作开发演示，上线前建议换成自己的素材。

挂坠上的 OpenAI 图标来自 Simple Icons v11.15.0 的 `icons/openai.svg`，使用本地资源（来源：https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/openai.svg）。

挂坠仅保留几何标志和绳线，移除了底色与外框。`src/pendant-contrast.js` 会读取挂坠下方的页面颜色及同源图片像素，依据亮度选择黑色或白色；滚动、拖动、页面切换和主题切换时自动更新。外部图片若禁止像素读取，退回页面背景色。绳端使用标志的旋转、平移后的实际挂点，包含手机尺寸，避免左右晃动时断开。
