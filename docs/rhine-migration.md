# 首页文章档案迁移

来源：`模板/RhineLabUI`，MIT，Copyright (c) 2026 LBEILC。
完整许可随模型保留在 `public/assets/rhine/LICENSE.txt`；Three.js 的许可位于 `public/assets/vendor/three/LICENSE`。

完整迁入原模板 `scene.ts` 及其 22 个渲染模块到 `src/rhine/`，仅去除 TypeScript 类型并适配文章数据、首页滚轮及资源路径。原模型、磨砂玻璃折射、内构材质、室内环境光、暖色灯光、2048 阴影、32 采样 AO、共享深度景深、阵列高低造型和长焦镜头均沿用源实现。选中/悬停竖直抬升 0.4，带波谷扩散、静止起伏、归位副本、自由平面拖动与持续惯性同样沿用源代码。循环坐标重置从原固定 5 列/8 份改为真实分类数与行数公倍周期。

HUD 按模板 1920×1080 坐标比例重排品牌、长横线、档案信息、序号、刻度及行列按钮。迁入原 MiSans 分片字体及来源与许可证，按实际文字按需载入。字样改为 BAIYE LAB / PERSONAL INFORMATION / ARCHIVE OS，档案印刷文字改为 BAIYE ARCHIVE，编号绑定文章。保留原档案标签的 MIT 几何标识。原商用 Novecento 字体、完整开机流程、原档案正文、模型查看器入口、声音、PWA/壁纸功能没有迁入。

博客文章通过 `ArticleArchive` 映射为档案；顺序为“全部文章 → 有文章的分类 → 有文章的标签”。分类/标签使用独立命名空间，同名 slug 不混组。多分类、多标签文章出现在每个匹配的组，每组独立记忆选中的文章；左右切组、上下选组内文章，默认按发布日期倒序，档案层不再提供排序按钮。行列持续循环，编号跟随文章稳定，UI 数量仅统计真实文章。左下角为“当前分组内文章序号 / 组内文章总数”，附悬停及无障碍说明。标题、简介、日期、分类与标签来自同一份博客数据，读取链接为现有 `/posts/:slug`。

原模板完整画质导致持续重绘开销较高。现采用 85% 渲染比例、DPR 上限 1、1024 阴影、半分辨率 16 采样 AO、85% 景深、半分辨率透光渲染，保留源材质与镜头。预热后连续 30 个有效帧平均间隔超过 28ms 时逐档降至 70%/55% 比例；暂停间隔不纳入采样，不反复升降画质。关闭静止起伏和鼠标视差，让原版帧缓存收敛；连续复用 12 帧后停止 RAF，指针、选档、主题、尺寸及可见性变化唤醒渲染。诊断数据位于 `.archive-stage` 的 `data-render-state`、`data-render-quality`、`data-frame-stats`，无需界面设置。

首次进入第三层播放约 6.4 秒的欢迎与阵列过渡：个人欢迎字样淡入，下方显示当前站点头像，停留 1.8 秒后沿用原 renderer 的 21.9–26.5 秒阵列镜头，逐字显示 SELECTING FILES、伸展横线、浮现编号，再显示文章与操作区。省略之后的详情抽取镜头；同一次首页内再次切回保留选档位置，不重复开场。离开中断开场，减少动画偏好下直接显示可操作界面。明暗模式沿用原版按档案位置扩散的材质过渡；HUD 跟随博客主题。手机将阵列放在上方、档案信息及控件放在下方，镜头使用源 portrait 构图。

第三层首次进入才加载 Three.js 与约 3.6 MB 原模型；隐藏层及后台标签页停止渲染，离开首页释放 WebGL 资源。加载失败跳过开场，仍可通过 DOM 按钮选文章、查看信息、进入阅读页。资源全部本地提供，无 CDN 运行依赖。

`npm run vendor:rhine` 重新生成模型、完整渲染模块、实际引用的 19 个 Three.js 扩展与字体（需要 Node.js 24、`npm install` 以及原模板目录）。`src/rhine/data.js` 是手写博客适配层，生成脚本不覆盖。已生成的静态资源直接随 `npm run build` 打包，正常开发和部署无需运行资源生成脚本。

首页滚轮仍切换整屏层。档案场景中拖动、点击选档，底部刻度/上下按钮选文章，左右按钮切分类；聚焦场景或档案控件时方向键选档，Enter 读取。PageUp/PageDown 和右侧层级圆点继续切层。
